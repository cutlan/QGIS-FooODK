# QGIS-FooODK
FooODK Plugin 
Readme 
--------------------- 
Summary 
The plugin utilize the OpenDataKit (ODK) Central API (based on OpenData Standards) to enhance rapid data manipulations and quality check on both spatial and non-spatial data in Quantum Geographic Information System (QGIS). It performs data plotting, export, geotagging image/picture and analysis (pivot, graphs and wordcloud).
